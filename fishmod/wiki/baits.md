# Bait

| Bait | Where to get it | Notes |
|---|---|---|
| Bare hook | Always available | Fishing without bait works, but most fish are less interested. |
| Bee Larva | Knock down a beehive and scoop the larvae with an empty bottle (10 per scoop) | Sweet bait; carp love it. |
| Bug | Any bottled bug | Wriggling live bait that bass go for. |
| Worm | Planned | Catfish favorite. |
| Coral Earring | Planned | A Zora heirloom; the only thing a Reekfish will bite. |
| Spinner | Planned | A flashing blade on a wire; reeled steadily. Predators chase it. |
| Crankbait | Planned | A plug that dives when reeled; reaches fish holding deeper. |
| Popper | Planned | Topwater lure: twitched, it pops and splashes on the surface. |
| Frog Lure | Planned | A soft frog worked over weeds and lily pads; the loach's weakness, as in Twilight Princess. |
| Sinking Lure | Planned | Ocarina of Time's sinking lure: sinks to the bottom where the biggest fish hold. |
