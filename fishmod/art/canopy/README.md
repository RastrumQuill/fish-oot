# Canopy textures

Top-down ground-cover textures for the raised canopy layer (a copy of the lake bed a few units up). Greyscale I4, 128×64 (the largest greyscale texture that fits in one 4 KB texture load); the game tints them.

| File | Plant | Made from |
|---|---|---|
| `pennywort.i4.png` | Pennywort (*Hydrocotyle* / *Centella*) mat | Photo supplied by the project owner, via `fishmod/tools/gen_canopy_tex.py --width 800 --overlap 72 --x 80 --y 360 --aspect 1.35` |

The source photo isn't committed. Confirm its licence and credit before a public release.
